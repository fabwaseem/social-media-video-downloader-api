# Snagbox palette

The mark is a download arrow dropping into a tray. Light and dark lockups share the gradient tile; the wordmark is ink on light backgrounds and paper on dark ones.

| Token | Hex | Use |
| --- | --- | --- |
| Ember | `#FF5E3A` | Gradient start |
| Magenta | `#FF2D87` | Gradient end |
| Ink | `#111827` | Wordmark and text on light backgrounds |
| Night | `#0B0B10` | Dark background |
| Paper | `#F9FAFB` | Wordmark on dark backgrounds |
| White | `#FFFFFF` | Arrow and tray |
