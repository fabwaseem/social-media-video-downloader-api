# Snagbox palette

The mark is a download arrow dropping into a tray. Light and dark lockups share one gradient tile; only the wordmark color changes.

| Token | Hex | Use |
| --- | --- | --- |
| Ember | `#FF5E3A` | Gradient start |
| Magenta | `#FF2D87` | Gradient end |
| Ink | `#111827` | Wordmark on light backgrounds |
| Paper | `#F9FAFB` | Wordmark on dark backgrounds |
| White | `#FFFFFF` | Arrow and tray |

Files: `logo-light.svg`, `logo-dark.svg`, `icon.svg`, `icon-512.png`, `favicon-32.png`, `social-preview.png`.
